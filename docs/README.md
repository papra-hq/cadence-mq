# CadenceMQ documentation

The documentation site is built with [Astro Starlight](https://starlight.astro.build/).

## Development

Run commands from the repository root:

```bash
pnpm --filter @cadence-mq/docs dev
pnpm --filter @cadence-mq/docs build
pnpm --filter @cadence-mq/docs preview
```

Documentation pages live in [`src/content/docs`](./src/content/docs).
